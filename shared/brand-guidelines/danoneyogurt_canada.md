# Danone Yogurt (incl. Danino) — Canada On-Site Content Profile

Market: Canada (bilingual EN/FR — Canadian English + Québec French). Source: Danone Canada SEO Content Rules doc.

For general Canada-wide legal/vocabulary/language conventions that apply to every brand, see `general_legal_canada.md` — this file covers only what's specific to Danone Yogurt / Danino Canada.

---

## Brand Rules

- Danonino is not cooked and does not go into recipes — never suggest cooking with it or using it as a recipe ingredient
- Children's products: no marketing addressed directly to children. Example specifically refused by legal: "your kids will want to collect them all!"

## Vocabulary

- "irresistibly" → not permitted — "Irresistible" is a competitor's name
- "Lactoseless" → use "Lactose free"
- Ingredients are "naturally sourced" — never "natural"
- Danino: say "drinkable yogurt," not "yogurt drink"
