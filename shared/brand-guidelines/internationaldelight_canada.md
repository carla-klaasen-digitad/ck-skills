# International Delight — Canada On-Site Content Profile

Market: Canada (bilingual EN/FR — Canadian English + Québec French). Source: Danone Canada SEO Content Rules doc.

For general Canada-wide legal/vocabulary/language conventions that apply to every brand, see `general_legal_canada.md` — this file covers only what's specific to International Delight Canada.

---

## Brand Rules

- "Plant-based" cannot be used for this brand at all
- Iced Coffees: there is no "real milk" in the product — never claim it
- "treat" → not permitted

## Vocabulary

- French: « crème à café » → not permitted; use « rehausseur à café ». In English, "coffee creamer" is fine.
- Sugar-free claims (EN) — use only one of: "sugar-free," "free of sugar," "no sugar," "0 sugar," "zero sugar," "without sugar," "contains no sugar," "sugarless," "0 g sugar," "zero g sugar," "0 gram sugar," "zero gram sugar"
- Sugar-free claims (FR) — use only one of: « sans sucre », « 0 sucre », « zéro sucre », « aucun sucre », « ne contient pas de sucre », « 0 g sucre », « zéro g sucre », « 0 gramme sucre », « zéro gramme sucre »
